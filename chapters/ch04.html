01 | 차시 개요와 시간 운영

이번 차시는 3차시에서 다룬 센서 값을 받아 판단 규칙을 코드로 표현하는 방법을 익힌다. 로봇을 움직이는 실제 제어 신호를 보내지 않고, 조향각과 속도를 숫자로 계산해 출력한다. 이 분리가 중요한 이유는 잘못된 조건문이 실제 모터를 갑자기 움직이게 하지 않도록 하기 위해서다.

필수 60분: 0~10분 변수·자료형, 10~20분 조건문, 20~30분 반복문, 30~40분 함수, 40~55분 종합 예제, 55~60분 확인. 선택 심화: 입력 유효성 검사와 테스트 케이스 추가.

성공 기준: 센서 거리 네 개를 순서대로 처리하고, 위험 거리 또는 측정 오류에는 정지 명령을 만든다. 함수의 반환값을 표준 출력으로 확인한다.

기술 구분: Python은 언어이며, 로봇 전용 통신 규약은 아니다. 본 실습의 Command는 교육용 데이터 구조일 뿐 알티노 AI의 제조사 명령 형식이 아니다.

02 | 센서에서 판단까지 데이터 흐름

센서가 제공하는 데이터는 원시 측정값이다. Python 프로그램은 측정값을 변수에 저장하고, 유효성 검사 후 규칙에 따라 출력 명령을 계산한다. 예를 들어 전방 거리가 0.3m일 때 정지 명령을 만드는 것은 제어 정책이며, 센서 자체의 기능이 아니다.

입력 → 처리 → 출력: front_m(전방 거리, 미터) → 거리값 유효성 검사 → 장애물 판단 → Command(조향각·속도·이유). 센서 값이 없거나 유효하지 않다면 정지하는 보수적 정책을 적용한다.

안전 경계: 계산한 명령은 화면에만 출력한다. 실제 모터를 연결하려면 제조사 통신 API, 긴급 정지, 속도 상한, 주행 구역, 전원 상태 검증이 추가로 필요하다. 이 차시는 그 연결을 구현하지 않는다.

생각해 보기: '거리 0.5m'는 센서가 측정한 물리량이고 '속도 0%'는 소프트웨어가 결정한 제어 명령이다. 둘을 혼동하면 오류 분석이 어려워진다.

03 | 변수와 기본 자료형

변수는 값을 보관하는 이름이다. front_m = 1.8은 전방 거리 1.8m를 front_m에 연결한다. Python은 실행 중 값에 따라 자료형을 판단한다. 정수 int, 실수 float, 문자열 str, 논리값 bool, 값 없음 None을 구별한다.

front_m = 1.8          # float: 거리 [m]
speed_pct = 35         # int: 속도 비율 [%]
direction = "left"    # str: 목표 방향
valid = front_m >= 0   # bool: 측정값 유효 여부
missing = None         # 측정값 부재
print(type(front_m).__name__, valid, missing)

예상 출력: float True None. None은 숫자 0과 다르다. 0m는 측정값이고 None은 측정이 이루어지지 않았다는 뜻이다.

실습: front_m을 0.2, 2.0, None으로 바꾸고 비교 연산을 실행한다. None >= 0은 TypeError가 발생하므로 숫자 비교 전에 None 검사가 필요하다.

주의: 센서 거리의 단위를 미터로 통일한다. 50을 센티미터로 받아놓고 미터 임계값 0.5와 직접 비교하면 잘못된 결과가 나온다.

04 | 연산자와 수치 범위 제한

산술 연산자 + - * /, 비교 연산자 < <= > >= == !=, 논리 연산자 and or not를 구분한다. 비교식의 결과는 True 또는 False이며, 조건문에 그대로 사용할 수 있다. =는 대입이고 ==는 같은 값인지 비교하는 연산이다.

front_m = 0.8
near = front_m < 1.0
critical = front_m < 0.5
print(near, critical)
requested_speed = 70
safe_speed = min(max(requested_speed, 0), 35)
print(safe_speed)

예상 출력: 첫 줄 True False, 둘째 줄 35. max는 하한을, min은 상한을 적용한다. 하지만 NaN(숫자가 아닌 값)이나 무한대 등은 별도로 검사해야 한다.

실습: 요청 속도를 -20, 20, 90으로 바꾸어 결과를 기록한다. 출력은 각각 0, 20, 35이다. 이 값은 실제 구동 속도가 아니라 교육용 비율이다.

검토 질문: 0.5가 경계값일 때 < 0.5와 <= 0.5는 어떻게 다른가? 이 교재에서는 정확히 0.5m일 때 주행 허용 쪽에 속한다. 실제 장비에는 여유거리와 제동거리를 추가 고려해야 한다.

05 | 조건문으로 위험 상황 판단

조건문은 상황에 따라 다른 경로를 실행한다. if는 첫 조건을 검사하고, elif는 앞 조건이 거짓일 때 검사하며, else는 나머지 경우에 실행된다. Python에서는 들여쓰기 자체가 문법이므로 동일 블록의 문장을 같은 깊이로 배치한다.

front_m = 0.8
if front_m < 0.5:
    speed_pct = 0
elif front_m < 1.0:
    speed_pct = 20
else:
    speed_pct = 35
print(speed_pct)

예상 출력: 20. 먼저 긴급 정지 조건을 확인하므로 0.3m는 속도 0%, 0.8m는 20%, 1.8m는 35%가 된다.

예외 상황: 센서 입력이 None이면 이 코드는 실패한다. 조건문 앞에서 입력 유효성을 먼저 확인하거나, 예제의 decide()처럼 실패 시 정지 명령을 반환해야 한다.

실습: 조건 순서를 바꾸어 front_m < 1.0을 먼저 검사하면 0.3m에서 왜 잘못된 결과가 나오는지 확인한다. 조건 순서는 제어 정책의 일부다.

06 | 반복문으로 여러 측정값 처리

실제 로봇은 센서 데이터를 한 번만 읽지 않는다. 반복문을 이용하면 연속된 입력을 처리할 수 있다. for는 준비된 데이터 집합을 순회하며, enumerate는 항목과 순번을 함께 제공한다. while은 조건이 참인 동안 반복하지만 종료 조건이 없다면 무한 반복이 된다.

distances = [1.8, 0.8, 0.3, None]
for index, front_m in enumerate(distances, start=1):
    if front_m is None:
        print(index, "측정 실패")
    else:
        print(index, f"{front_m:.1f}m")

예상 출력: 1 1.8m, 2 0.8m, 3 0.3m, 4 측정 실패. is None은 값이 없음을 확인할 때 사용한다.

실습: 리스트에 0.5와 1.0을 추가하고 출력 순서를 확인한다. 반복문 내부에서 리스트를 임의 변경하지 않는다.

안전: 실물 로봇에 while True를 적용한다면 반드시 주기 제한, 종료 조건, 통신 끊김 시 정지, 예외 처리, 하드웨어 긴급 정지가 필요하다. 본 실습은 유한한 리스트만 순회한다.

07 | 함수로 판단 규칙 분리

함수는 입력을 받아 결과를 반환하는 재사용 가능한 코드 단위다. def로 정의하고, return으로 결과를 돌려준다. 함수가 화면 출력까지 모두 수행하면 재사용과 자동 테스트가 어려워지므로, 판단 함수는 값을 반환하고 화면 출력은 별도 함수가 담당하도록 나눈다.

def choose_speed(front_m):
    if front_m is None or front_m < 0:
        return 0
    if front_m < 0.5:
        return 0
    if front_m < 1.0:
        return 20
    return 35

print(choose_speed(1.8))
print(choose_speed(0.3))

예상 출력: 35, 0. return을 실행하면 함수는 즉시 종료된다. 함수 내부 변수는 바깥에서 직접 사용할 수 없으며, 필요한 값은 인자와 반환값으로 전달한다.

실습: 임계값을 함수 인자로 분리하는 choose_speed(front_m, stop_limit=0.5)를 만들어 본다. 기본 인자는 호출 시 생략할 수 있지만, 안전 임계값은 임의 변경하지 않도록 관리해야 한다.

연결: 다음 차시의 NumPy에서는 여러 거리 데이터를 배열로 묶어 처리하지만, 입력 검증과 판단 함수 분리 원칙은 동일하다.

08 | 리스트·딕셔너리와 데이터 구조

리스트 list는 순서가 있는 여러 값을 보관한다. 딕셔너리 dict는 이름을 키로 하여 값을 찾는다. 센서 데이터는 리스트로, 설정값은 딕셔너리로 표현할 수 있다. 키를 잘못 쓰면 KeyError가 발생할 수 있으므로 get 또는 명시적 검증을 사용한다.

distances = [1.8, 0.8, 0.3]
settings = {"stop_m": 0.5, "slow_m": 1.0}
print(len(distances), min(distances))
print(settings["stop_m"])

예상 출력: 3 0.3, 0.5. min은 리스트의 최소값을 반환하지만 빈 리스트에 적용하면 오류가 난다. 또한 None이 섞인 리스트는 숫자만 추출한 후 최소값을 계산해야 한다.

실습: 거리 리스트에 None을 추가하고 다음 표현을 실행한다.

valid = [d for d in distances if d is not None and d >= 0]
print(min(valid) if valid else "유효 측정값 없음")

핵심: 빈 입력을 정상적인 0m 측정으로 바꾸면 안 된다. '측정 실패'와 '장애물이 매우 가까움'은 모두 정지할 수 있지만, 기록되는 원인은 다르다.

10 | 전체 실습 코드와 실행 결과

제공된 robot_python_lab.py는 Command 데이터 클래스, clamp(), decide(), run_scenario(), main()으로 구성된다. 코드는 하드웨어에 연결되지 않으며 화면 출력만 수행한다. decide()는 거리 입력이 없거나 유한한 수가 아니면 정지하고, 목표 방향이 사전에 정의된 값이 아니어도 정지한다.

실행: python codes/ch04/robot_python_lab.py

예상 출력:

1: 조향=-15도 속도=35% / 모의 명령
2: 조향=-15도 속도=20% / 모의 명령
3: 조향=0도 속도=0% / 전방 장애물: 정지
4: 조향=0도 속도=0% / 거리 측정 오류: 정지

코드 풀이: @dataclass(frozen=True)는 결과 명령을 한 묶음으로 표현하고 필드 재대입을 막는다. direction_to_angle 딕셔너리는 방향 문자열을 조향각에 대응시킨다. run_scenario의 리스트 컴프리헨션은 각 입력마다 decide를 호출해 결과 리스트를 만든다. if __name__ == '__main__'은 파일을 직접 실행했을 때만 main()을 호출한다.

핵심 코드 전체:

"""04차시: 로봇 명령을 생성하는 Python 기초. 실제 모터를 구동하지 않는다."""
from dataclasses import dataclass
from math import isfinite

@dataclass(frozen=True)
class Command:
    steering_deg: float
    speed_pct: float
    reason: str

def clamp(value: float, low: float, high: float) -> float:
    """안전한 출력 범위로 제한한다."""
    if not isfinite(value):
        raise ValueError('값은 유한한 수여야 합니다')
    if low > high:
        raise ValueError('범위의 최소값이 최대값보다 큽니다')
    return min(max(value, low), high)

def decide(front_m: float | None, target_direction: str) -> Command:
    """거리와 목표 방향으로 모의 주행 명령을 만든다."""
    if front_m is None or not isfinite(front_m) or front_m < 0:
        return Command(0.0, 0.0, '거리 측정 오류: 정지')
    if front_m < 0.5:
        return Command(0.0, 0.0, '전방 장애물: 정지')
    direction_to_angle = {'left': -15.0, 'straight': 0.0, 'right': 15.0}
    if target_direction not in direction_to_angle:
        return Command(0.0, 0.0, '알 수 없는 방향: 정지')
    speed = 20.0 if front_m < 1.0 else 35.0
    return Command(direction_to_angle[target_direction], speed, '모의 명령')

def run_scenario(measurements: list[float | None], direction: str) -> list[Command]:
    """반복문으로 센서 샘플을 순서대로 처리한다."""
    return [decide(distance, direction) for distance in measurements]

def main() -> None:
    distances = [1.8, 0.8, 0.3, None]
    for index, command in enumerate(run_scenario(distances, 'left'), start=1):
        print(f'{index}: 조향={command.steering_deg:.0f}도 속도={command.speed_pct:.0f}% / {command.reason}')

if __name__ == '__main__':
    main()

<a id="section-11"></a>

11 | 오류 점검과 자동 테스트

자동 테스트는 같은 입력에 대해 항상 같은 출력이 나오는지 확인한다. unittest는 Python 표준 라이브러리이므로 별도 설치가 필요하지 않다. 테스트는 실제 로봇이 안전하다는 증명이 아니라, 모의 판단 함수가 정해진 규칙을 지키는지 확인하는 절차다.

검증 사례: (1) 속도 상한 초과 제한 (2) 하한 미만 제한 (3) 잘못된 범위 (4) NaN 거부 (5) 근접 장애물 정지 (6) 측정값 없음 정지 (7) 음수 거리 정지 (8) 미등록 방향 정지 (9) 좌회전 각도 (10) 우회전 각도 (11) 감속 구간 (12) 반복 처리 개수.

실행: python -m unittest discover -s codes/ch04 -v → 12개 테스트의 OK가 기대된다.

오류별 점검: ModuleNotFoundError는 작업 폴더와 모듈 경로를 확인한다. IndentationError는 들여쓰기를 확인한다. TypeError는 None과 숫자를 비교했는지 점검한다. ValueError는 입력 범위 및 문자열 숫자 변환을 확인한다.

실습: decide(0.5, 'straight')와 decide(1.0, 'straight')의 결과를 예상하고 실제로 확인한다. 두 경계값에서 각각 감속(20%)과 정상(35%)으로 판정한다.

자동 테스트 전체:

import unittest
from robot_python_lab import clamp, decide, run_scenario

class RobotPythonTests(unittest.TestCase):
    def test_clamp(self): self.assertEqual(clamp(50, 0, 30), 30)
    def test_clamp_low(self): self.assertEqual(clamp(-5, 0, 30), 0)
    def test_clamp_bad_range(self):
        with self.assertRaises(ValueError): clamp(1, 5, 0)
    def test_clamp_nan(self):
        with self.assertRaises(ValueError): clamp(float('nan'), 0, 1)
    def test_stop_near(self): self.assertEqual(decide(0.2, 'left').speed_pct, 0)
    def test_stop_none(self): self.assertEqual(decide(None, 'left').speed_pct, 0)
    def test_stop_negative(self): self.assertEqual(decide(-1, 'left').speed_pct, 0)
    def test_stop_bad_direction(self): self.assertEqual(decide(2, 'up').speed_pct, 0)
    def test_left(self): self.assertEqual(decide(2, 'left').steering_deg, -15)
    def test_right(self): self.assertEqual(decide(2, 'right').steering_deg, 15)
    def test_slow(self): self.assertEqual(decide(.8, 'straight').speed_pct, 20)
    def test_loop(self): self.assertEqual(len(run_scenario([1,2,None], 'left')), 3)

if __name__ == '__main__': unittest.main()

종합 실습: 거리 샘플 [1.8, 0.8, 0.3, None]과 목표 방향 left를 입력해 네 개의 Command를 만든다. 각 결과에서 조향각, 속도, 이유를 출력하고, 위험한 경우 속도가 0인지 검사한다. 제공된 코드를 먼저 실행한 뒤 거리 샘플을 바꾸어 재실행한다.

13. 선택 심화 — 센서 문자열 입력 오류와 방어적 프로그래밍

기존 필수 실습에서 decide()는 거리값이 정상이면 모의 조향·속도 명령을 만들고, None·음수·무한대 같은 입력은 정지로 바꾸었다. 실제 프로그램의 외부 데이터에는 숫자만 입력된다는 보장이 없다. 파일이나 통신 장치에서 수신한 값은 "0.8"과 같은 문자열일 수도 있고, "nan", "bad", 빈 문자열, 누락값일 수도 있다. 문자열 입력 → 수치 변환 → 유효성 검사 → 안전 판단 → 로그 기록을 개별 함수로 분리해야 오류 발생 위치를 추적할 수 있다.

입력 파싱 결과 모의 제어 판단 이유
"1.8" 1.8m 속도 35% 정상
"0.8" 0.8m 속도 20% 감속
"bad" 없음 속도 0% 형식 오류 정지
"-1" 없음 속도 0% 물리적으로 불가능한 거리
"nan" 없음 속도 0% 유효하지 않은 수치
"0.3" 0.3m 속도 0% 가까운 장애물

float() 변환은 문자열이 숫자가 아니면 ValueError를 발생시킨다. 반대로 float("nan")과 float("inf")는 예외 없이 변환되므로 반드시 math.isfinite()로 구분한다. 입력 오류를 숫자 0으로 변경하면 실제 장애물 거리 0m와 센서 장애를 구별할 수 없으므로 이번 예제는 None으로 표현한다. 정지 원인까지 기록하는 이유는 고장 분석과 재현 가능한 교육 평가를 지원하기 위해서다.

13-1. 예외 처리 코드의 핵심

from math import isfinite

def parse_distance(raw):
    try:
        number = float(raw)
    except (ValueError, TypeError):
        return None
    return number if isfinite(number) and number >= 0 else None

문자열이 숫자로 변환되더라도 음수, 무한대, NaN(낫 어 넘버, 유효하지 않은 수치)은 반려한다. 반환 결과인 None은 기존 04차시 decide()에서 모의 안전 정지로 연결된다. 실제 장비의 긴급 정지 기능을 대신하지 않으며, 이 실습의 속도 백분율은 실물 모터 명령이 아니다.

14. 선택 심화 — 입력·판단·CSV 로그까지 전체 프로그램

실습 파일: codes/ch04/robust_scenario.py. 기존 robot_python_lab.py의 decide()를 가져와 재사용한다. 실습 후에는 codes/ch04/output/decisions.csv가 생성되며 표 계산 프로그램으로 열어 입력, 거리 해석, 판단 결과를 행 단위로 검사할 수 있다. 신호 수신 및 장비 명령 전송 기능은 포함하지 않는다.

전체 코드(실제로 자동 테스트를 수행한 파일과 동일):

"""04차시 선택 실습: 안전한 거리 데이터 입력, 판정, CSV 기록(모의 명령)."""
from pathlib import Path
from csv import DictWriter
from math import isfinite
from robot_python_lab import decide


def parse_distance(raw):
    """센서 문자열을 미터 값으로 변환; 비정상 값은 None으로 정규화한다."""
    try:
        number = float(raw)
    except (ValueError, TypeError):
        return None
    return number if isfinite(number) and number >= 0 else None


def make_log(rows, direction='straight'):
    """센서 입력→예외 처리→명령 생성→감사 가능한 기록을 만든다."""
    output = []
    for index, value in enumerate(rows, 1):
        distance = parse_distance(value)
        cmd = decide(distance, direction)
        output.append({'sequence': index, 'raw': str(value),
                       'distance_m': '' if distance is None else distance,
                       'steering_deg': cmd.steering_deg,
                       'speed_pct': cmd.speed_pct,
                       'reason': cmd.reason})
    return output


def save_csv(output, path):
    """외부 장비에 명령을 보내지 않고 로컬 CSV 파일만 저장한다."""
    dest = Path(path)
    dest.parent.mkdir(parents=True, exist_ok=True)
    with dest.open('w', encoding='utf-8-sig', newline='') as f:
        writer = DictWriter(f, fieldnames=['sequence', 'raw', 'distance_m',
                                         'steering_deg', 'speed_pct', 'reason'])
        writer.writeheader()
        writer.writerows(output)
    return dest


if __name__ == '__main__':
    readings = ['1.8', '0.8', 'bad', '-1', 'nan', '0.3', '2.0']
    log = make_log(readings, 'left')
    for row in log:
        print(f"{row['sequence']}: {row['raw']:>5} → 속도 {row['speed_pct']:.0f}% / {row['reason']}")
    print('CSV 저장:', save_csv(log, Path(__file__).parent / 'output' / 'decisions.csv'))

실행 절차 (프로젝트 최상위 폴더):

python -m unittest discover -s codes/ch04 -p 'test_*.py' -v

예상 결과는 7개 입력에 대해 정상 3건, 감속 1건, 정지 3건을 포함한다. bad, -1, nan이 각각 별도의 행으로 남는지 확인한다. 출력 CSV에서 distance_m이 빈 칸인 경우는 센서값 파싱 실패를 나타내며 속도 0.0으로 기록되어야 한다.
