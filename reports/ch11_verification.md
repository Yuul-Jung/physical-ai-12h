# 11차시 기술·적대적 검증 보고서

- 대상: 신호등·방향 화살표·주차 표지 합성 영상 인식
- Markdown A4 인쇄: 11페이지 (WeasyPrint PDF 렌더링)
- HTML A4 인쇄: 10페이지 (WeasyPrint PDF 렌더링)
- 단위 테스트: 7종 통과
- 구문 검사: 2개 파일 통과
- 합성 영상: 4개 PNG 생성
- SVG 경로·HTML 이전 차시·목차 링크: 검사 통과
- 개인정보/토큰/절대 사용자 경로 패턴: 탐지 없음
- 적대적 검증: 고정 ROI와 단일 픽셀의 취약성, 주차 표지 오검출, 영상 지연, 장애물 정지 우선순위, 실차 연동 미검증 명시
- 수정 이력: 화살표 좌우 분류 실패를 테스트에서 발견해 샘플 위치 수정 후 재검증
- 미검증: 알티노 AI 공식 SDK/실물 카메라·라이다·모터·안전 장치; 실도로 일반화 성능; 학습형 AI 모델
- 공식 참조: https://docs.opencv.org/4.x/ ; https://numpy.org/doc/stable/ ; https://docs.python.org/3/library/unittest.html
- 12차시 예정 링크는 존재하지 않으므로 비활성 문구로 표시
